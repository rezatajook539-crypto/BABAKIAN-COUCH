# ApexCodeTeam — Instagram Cover

## Chosen direction
- **Primary style:** Brutalist condensed typography — a bold, high-contrast gym-oriented direction that speaks to the target audience of bodybuilding gyms.
- **Secondary accent:** Spot-color minimal — restrained red/black/white palette and technical grid details.
- **Format:** 1080 × 1350 px (4:5 vertical).

## Approved palette
- Red: `#EC141C`
- Deep red: `#DC141C`
- Black: `#040404`
- White: `#FCFCFC`
- Gray: `#707070`

Full palette variants are stored in `instagram-cover-palette.json`.

## Persian font
The repository already contains `font/BYekan.ttf`. No duplicate font was added. Use the existing font with `@font-face` for Persian website assets; for example, load `../font/BYekan.ttf` from a stylesheet inside `css/`. The exported cover images use a locally available Persian-capable font for correctly shaped Persian text.
